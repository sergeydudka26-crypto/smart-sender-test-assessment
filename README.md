# Smart Sender - Тестове завдання (Senior Frontend Engineer)

Цей проєкт реалізує базовий застосунок з авторизацією, списком вебхуків та механізмом керування сесіями, відповідно до вимог Smart Sender.

## Примітка щодо часу виконання

Виконання завдання зайняло приблизно **10-12 годин**. Реалізація повнофункціонального застосунку з дотриманням усіх вимог (авторизація, безпечна робота з сесіями, конкурентність API, CSRF-захист, обробка помилок та пагінація) з нуля за 4 години є технічно малоймовірною без використання повноцінних AI-агентів для автоматизації написання коду.

## Запуск застосунку

1. Встановлення залежностей:

    ```bash
    pnpm install
    ```

2. Запуск локального серверу розробки:

    ```bash
    pnpm dev
    ```

3. Відкрийте [](http://localhost:3000)<http://localhost:3000> у браузері.

## Запуск тестів

Для автоматизованого тестування використовується **Vitest** разом із **MSW**.

Запуск тестів:

```bash
npx vitest
```

Тест перевіряє коректність роботи механізму `rotate` при виникненні паралельних 401 помилок.
